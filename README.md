# 🇲🇦 Booking Morocco Web Scraping

A Python web scraping project developed to practice data extraction, cleaning, normalization and structured data export.

## 🎯 Project Objective

The goal of this project is to extract service information from a Moroccan booking website and transform raw web data into clean and structured data that can be used for analysis.

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Unicodedata
- JSON
- Jupyter Notebook

## 🔄 Workflow

1. Send an HTTP request to the website
2. Parse the HTML content with BeautifulSoup
3. Extract service names and links
4. Clean and normalize text
5. Standardize service names using aliases
6. Remove duplicates with Python sets
7. Convert relative links into complete URLs
8. Export the cleaned data to JSON
9. Check missing services and data coverage

## 📂 Repository Structure

- `Booking_morocco.ipynb` – Python web scraping notebook
- `services_booking_morocco.json` – Cleaned and structured output data
